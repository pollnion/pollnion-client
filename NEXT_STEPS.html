Backend & Auth Foundation
Before any UI works, you need data
Do First
Set up Supabase project Supabase
Create a Supabase project, grab your API keys, and add them to .env using the EXPO_PUBLIC_ prefix (already scaffolded in .env.example).
Design the database schema Supabase
Tables needed: profiles (extends auth.users), polls (question, options, creator_id, created_at), votes (user_id, poll_id, option_index), follows (follower_id, following_id). Enable Row Level Security on all.
Implement authentication Supabase Auth
Phone number OTP is ideal for a TikTok-style app. Or start with email magic link. Create src/lib/supabase.ts client and an app/(auth)/ route group for sign-in/sign-up screens.
Set up TanStack Query Data fetching
Install @tanstack/react-query, add QueryClientProvider to the root layout, and create a base src/lib/query-client.ts. This is your data-fetching backbone.
Auth-aware root layout + protected routes Expo Router
Update app/_layout.tsx to check auth state and redirect unauthenticated users to (auth) group, authenticated users to (tabs).

Core Poll Features
The actual reason the app exists
Build Second
Replace Explore tab → TikTok-style poll feed
Use a FlatList (or FlashList from Shopify for perf) with pagingEnabled and vertical snapping. Each item takes the full screen. Fetch paginated polls via TanStack Query + Supabase.
Poll card component
The star of the app. A full-screen card showing: the question, 2–4 answer options as tappable buttons, creator avatar + username, and a vote count. Show results as animated bars after the user votes.
Voting logic
On tap: optimistic update with TanStack Query, write vote to Supabase, disable re-voting. Store voted poll IDs locally (AsyncStorage) so state persists across sessions.
Create Poll screen
A form screen (accessible from a "+" button or FAB) to write a question and 2–4 answer options. Validate inputs, insert into Supabase, then dismiss back to the feed.
Replace Home tab → "For You" personalized feed
Show polls from people the user follows. Fall back to trending polls for new users. Use Supabase RPC or a simple view for the query.

Social Layer
What makes users come back for others
Build Third
User profiles
A screen showing avatar, username, bio, follower/following counts, and a grid of their polls. Edit profile should let them update display name and avatar (upload to Supabase Storage).
Follow / unfollow
Write to the follows table. Update the "For You" feed query to factor in follows. Show a Follow button on poll cards and profile screens.
Reactions & comments (lightweight)
Start simple: emoji reactions on polls (heart, fire, thinking face). Comments can come later — they add complexity without impacting core retention in v1.
Search / Discover screen
A dedicated screen to search polls by keyword or browse by topic/hashtag. Use Supabase full-text search or a simple ilike query to start.
Share polls
Use expo-sharing or React Native's Share API to share a deep-link URL. Configure Supabase Edge Functions + Vercel to serve open graph preview cards.

Retention & Polish
What makes it feel alive and addictive
Polish
Push notifications expo-notifications
Notify users when: someone follows them, a poll they created gets 10/50/100 votes, or a followed user posts a new poll. Store push tokens in Supabase and send via Edge Functions.
Trending algorithm
A Supabase database function or view that scores polls by: recent votes × recency decay. Use as the default "Explore" feed for unauthenticated or new users.
Smooth animations & micro-interactions
Vote result bars animate in with react-native-reanimated. Add swipe-up gesture between polls. Haptic feedback on vote (already have expo-haptics installed).
App Store / Play Store prep
